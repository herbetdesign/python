# Conversor de Imagens PNG para JPEG  

Este script em Python converte imagens no formato PNG para JPEG, garantindo compatibilidade e compressão eficiente.  

## 📌 Funcionalidades  

- Converte imagens PNG para JPEG.  
- Remove transparência de imagens PNG (se necessário).  
- Define qualidade de compressão do JPEG.  
- Exibe as imagens antes e depois da conversão.  

## 🛠️ Requisitos  

Antes de executar o script, instale as bibliotecas necessárias:  
```
pip install pillow matplotlib
```

## 🚀 Como Usar
1. Baixe o script deste repositório.
2. Certifique-se de ter as dependências instaladas (Pillow e Matplotlib).
3. Execute o script informando o caminho do arquivo PNG e o nome do arquivo de saída em JPEG.
