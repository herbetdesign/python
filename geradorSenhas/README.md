# Gerador de Senhas Fortes
## Descrição
Este script Python gera senhas fortes e seguras utilizando combinações de letras (maiúsculas e minúsculas), números e símbolos. Ele é ideal para criar senhas que atendam aos requisitos de segurança modernos, como os necessários para proteger contas online ou sistemas sensíveis.
O programa permite ao usuário definir o tamanho da senha desejada e exibe a senha gerada no terminal para ser copiada e utilizada onde for necessário.

## Funcionalidades
1. Geração de senhas aleatórias e seguras.
2. Tamanho da senha personalizável (com valor padrão de 12 caracteres).
3. Combinação de letras, números e símbolos para garantir força máxima.
4. Execução simples diretamente no terminal.

## Pré-requisitos
Antes de executar o script, certifique-se de ter o seguinte instalado:
1. Python 3.x instalado no sistema.
2. Bibliotecas padrão do Python (random e string) - não é necessário instalar bibliotecas adicionais.
